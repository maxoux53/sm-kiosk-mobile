# sm-kiosk-mobile

## Installation de l'API

1. Cloner le projet depuis le dépôt GitHub :
   ```bash
   git clone https://github.com/maxoux53/sm-kiosk.git
   ```
2. Ajouter le fichier `.env` fournit
3. Ouvrir un terminal et naviguer jusqu'au répertoire du projet.
4. Executer la commande suivante :
   ```bash
   docker-compose up --build -d
   ```
5. Se conneter à l'aide des identifiants trouvés login.txt

## Installation de l'application mobile

1. Cloner le projet depuis le dépôt GitHub :
   ```bash
   git clone https://github.com/maxoux53/sm-kiosk-mobile.git
   ```
2. Executer la commande suivante pour installer les dépendances :
   ```bash
   npm i
   ```
3. Executer la commande suivante pour lancer l'application :
   ```bash
   npm run start
```
